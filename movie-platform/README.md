# سينما العرب 🎬

تطبيق واجهة عربية (RTL) للأفلام والمسلسلات مبني باستخدام React وVite وTailwind CSS. يضمّ مكتبة تجريبية، بحثًا وتصنيفات وترتيبًا، قائمة مفضلة، صفحة مشاهدة، ولوحة لإضافة الأعمال وتعديلها وحذفها.

## التشغيل المحلي

يتطلب Node.js **20.19 أو أحدث**.

```bash
npm install
npm run dev
```

افتح العنوان الذي يظهر في الطرفية (عادةً `http://localhost:5173`).

بيانات الدخول **التجريبية فقط** في `/admin/login`: `admin` / `admin123`.

## إضافة محتوى

من لوحة الإدارة، أدخل بيانات العمل وصورة الملصق، ثم أضف واحدًا من الآتي:

- رابط YouTube/Vimeo أو كود `iframe` منهما. يُستخرج رابط المشغّل فقط ولا يُعرض HTML غير موثوق.
- رابط HTTPS لفيديو مباشر لديك حق عرضه (مثل MP4)، مع رابط ترجمة عربية بصيغة WebVTT (`.vtt`) اختياري. يمكن وضع ملفات ثابتة داخل `public/media/` واستخدام المسار `/media/your-video.mp4`. قد تتطلب ملفات الفيديو والترجمة الخارجية إعداد CORS على الخادم المُضيف.

المحتوى التجريبي المرفق يحتوي على **ملصقات ومقاطع دعائية فقط**، وليس أفلامًا أو حلقات كاملة أو نسخًا مترجمة؛ يُرجى استخدام محتوى تملك حقوق نشره أو لديك ترخيص لبثّه. حقوق الأعمال والملصقات لأصحابها.

## النشر

```bash
npm run build
npm start
```

- **Vercel:** اربط المستودع وحدد مجلد `movie-platform` كمجلد رئيسي إن كان داخل مستودع أكبر. يحتوي `vercel.json` على إعداد البناء وتوجيه صفحات SPA.
- **Railway:** اربط المستودع وحدد مجلد المشروع كـ Root Directory؛ يحتوي `railway.json` على أمر البناء وأمر التشغيل. يستخدم `server.js` منفذ البيئة `PORT` ويخدم ملفات `dist` مع fallback لروابط React Router.

## تنبيه مهم قبل الاستخدام العام

هذه **نسخة عرض بواجهة أمامية فقط**: بيانات الأفلام والمفضلة وحالة الدخول محفوظة في `localStorage` لكل متصفح على حدة. كلمة المرور موجودة في كود الواجهة، ويمكن تجاوز الحارس الأمامي؛ **ليست مصادقة أو لوحة إدارة آمنة، ولا تتزامن الإضافات بين المستخدمين**. نشر الملفات على Vercel/Railway لا يغيّر ذلك. لاستخدامها كموقع حقيقي يحتاج إلى قاعدة بيانات مشتركة، خادم بمصادقة وتفويض آمنين، ونظام رفع/استضافة وحقوق بث وترجمة مناسب. تستطيع تنزيل نسخة JSON احتياطية من لوحة الإدارة.

## بنية الملفات

- `src/data/sampleMovies.js`: أعمال توضيحية تُضاف عند فتح الموقع لأول مرة فقط.
- `src/utils/storage.js`: تخزين الأعمال والمفضلة والدخول التجريبي.
- `src/utils/media.js`: تحويل روابط المشاهدة إلى روابط YouTube/Vimeo موثوقة والتحقق من الوسائط.
- `src/pages/`: الرئيسية والمشاهدة وتسجيل الدخول والإدارة.
- `public/images/`: صور وملصقات محلية بحيث تعمل واجهة المثال بلا اعتماد على روابط صور خارجية.
