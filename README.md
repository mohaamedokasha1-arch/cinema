# سينما العرب 🎬

تطبيق واجهة عربية (RTL) للأفلام والمسلسلات مبني باستخدام React وVite وTailwind CSS. يضمّ مكتبة أعمال مختارة، بحثًا وتصنيفات وترتيبًا، قائمة مفضلة، صفحة مشاهدة، ولوحة إدارة محمية بتسجيل دخول يُتحقّق منه على الخادم.

## التشغيل المحلي

يتطلب Node.js **20.19 أو أحدث**.

```bash
npm install
cp .env.example .env.local   # ثم املأ القيم كما في قسم «تأمين لوحة الإدارة»
npm run dev
```

افتح العنوان الذي يظهر في الطرفية (عادةً `http://localhost:5173`). يعمل خادم التطوير على تقديم واجهة المصادقة نفسها المستخدمة في الإنتاج عبر المسار `/api/admin/*`.

## تأمين لوحة الإدارة

- بيانات الدخول **لا توجد في كود الواجهة** ولا في المستودع. يقرأ الخادم اسم المستخدم وبصمة كلمة المرور من متغيرات البيئة.
- كلمة المرور تُخزَّن كبصمة `scrypt` مملّحة (`ADMIN_PASSWORD_HASH`)، ولا تُخزَّن نصًا صريحًا في أي مكان.
- بعد الدخول يصدر الخادم كوكي جلسة موقّعًا بـ HMAC-SHA256، بخصائص `HttpOnly` و`SameSite=Strict` و`Secure` عند العمل عبر HTTPS، ومدة صلاحية 8 ساعات.
- كل طلب إلى `/api/admin/session` يتحقّق من التوقيع والصلاحية والانتهاء على الخادم. حذف الكوكي أو التلاعب بها لا يمنح أي صلاحية.
- تُرفض الطلبات ذات `Origin` مختلف، ويُقيَّد تكرار محاولات الدخول الخاطئة (5 محاولات ثم إيقاف 15 دقيقة).

### 1. توليد بيانات الدخول

```bash
npm run admin:hash -- --generate
```

يطبع الأمر كلمة مرور قوية (24 حرفًا)، وقيمة `ADMIN_PASSWORD_HASH`، وقيمة `SESSION_SECRET` عشوائية. اعتبر هذا الناتج سرًّا: لا تضعْه في Git ولا في كود الواجهة.

أو لاختيار كلمة المرور بنفسك:

```bash
ADMIN_PASSWORD='كلمة-مرور-قوية-بطول-12-حرفًا-على-الأقل' npm run admin:hash
```

### 2. ضبط المتغيرات

| المتغير | الوصف |
| --- | --- |
| `ADMIN_USERNAME` | اسم مستخدم لوحة الإدارة (اختياري، الافتراضي `admin`). |
| `ADMIN_PASSWORD_HASH` | ناتج الأمر أعلاه. مطلوب. |
| `SESSION_SECRET` | سر عشوائي بطول 32 حرفًا على الأقل لتوقيع الجلسات. مطلوب. |

- **محليًا:** ضع القيم في `.env.local` (مستثنى من Git عبر `.gitignore`).
- **Vercel:** Project → Settings → Environment Variables، وأضف المتغيرات الثلاثة لنطاق Production (و Preview إن رغبت) ثم أعد النشر.
- **Railway أو أي خادم Node:** أضف المتغيرات في تبويب Variables ثم أعد التشغيل.

إذا لم تُضبط المتغيرات، تُغلق لوحة الإدارة تلقائيًا وتعيد واجهة الدخول `503` بدل السماح بأي دخول، ويظل الموقع العام يعمل بشكل طبيعي.

### 3. واجهات المصادقة

| المسار | الطريقة | الوظيفة |
| --- | --- | --- |
| `/api/admin/login` | `POST` | التحقق من بيانات الدخول وإصدار كوكي الجلسة. |
| `/api/admin/session` | `GET` | التحقق من الجلسة الحالية. |
| `/api/admin/logout` | `POST` | إنهاء الجلسة ومسح الكوكي. |

تُنفَّذ هذه الواجهات في Vercel عبر دوال `api/admin/*`، وفي خادم Node عبر `server.js`، وفي التطوير عبر إضافة Vite — جميعها تستخدم `server/auth.js` نفسه.

## إضافة محتوى

من لوحة الإدارة، أدخل بيانات العمل وصورة الملصق، ثم أضف واحدًا من الآتي:

- رابط YouTube/Vimeo أو كود `iframe` منهما. يُستخرج رابط المشغّل فقط ولا يُعرض HTML غير موثوق.
- رابط HTTPS لفيديو مباشر لديك حق عرضه (مثل MP4)، مع رابط ترجمة عربية بصيغة WebVTT (`.vtt`) اختياري. يمكن وضع ملفات ثابتة داخل `public/media/` واستخدام المسار `/media/your-video.mp4`. قد تتطلب ملفات الفيديو والترجمة الخارجية إعداد CORS على الخادم المُضيف.

المحتوى المرفق يحتوي على **ملصقات ومقاطع دعائية فقط**، وليس أفلامًا أو حلقات كاملة أو نسخًا مترجمة؛ يُرجى استخدام محتوى تملك حقوق نشره أو لديك ترخيص لبثّه. حقوق الأعمال والملصقات لأصحابها.

> ملاحظة: قائمة الأعمال والمفضلة تُحفظ في `localStorage` داخل المتصفح، لذا تخصّ كل متصفح على حدة. المصادقة على لوحة الإدارة تحمي الدخول إلى اللوحة وواجهاتها، لكن مشاركة التعديلات بين الزوار تحتاج قاعدة بيانات مشتركة وواجهات كتابة محمية على الخادم. استخدم زر «نسخة احتياطية» في اللوحة للاحتفاظ بنسخة JSON من المكتبة.

## الاختبارات والتحقق

```bash
npm test                              # بناء + اختبارات الخادم والتحقق
npm run check:deploy -- https://cinema-elarab.vercel.app
```

- `npm test` يشغّل 12 اختبارًا: وجود وسم التحقق من Google Search Console داخل `<head>`، رفض كلمة المرور أو اسم المستخدم الخطأ، إصدار كوكي `HttpOnly`، رفض الكوكي المزوّر أو المعدّل، إضافة `Secure` عبر HTTPS، الخروج، رفض المصدر المختلف، 405/404، تقييد المحاولات، وإغلاق الدخول (503) عند غياب الإعدادات مع بقاء الموقع العام متاحًا.
- `check:deploy` فحص للقراءة فقط على أي نسخة منشورة: الصفحة الرئيسية والحزمة والصور والمسارات، وخلوّ حزمة JavaScript من أي أسرار، وجاهزية خدمة الدخول، ورفضها لبيانات غير معروفة.

## النشر

```bash
npm run build
npm start
```

- **Vercel:** اربط المستودع واترك Root Directory على جذر المشروع. يبني `vercel.json` مجلد `dist`، ويوجّه مسارات SPA مع إبقاء `/api/*` لدوال الخادم. بعد أول نشر أضف متغيرات البيئة الثلاثة وأعد النشر.
- **Railway:** اربط المستودع وحدد مجلد المشروع كـ Root Directory؛ يحتوي `railway.json` على أمر البناء وأمر التشغيل. يستخدم `server.js` منفذ البيئة `PORT` ويخدم ملفات `dist` مع fallback لروابط React Router.

## بنية الملفات

- `data/sampleMovies.js`: الأعمال الابتدائية التي تُضاف عند فتح الموقع لأول مرة فقط، مع قائمة التصنيفات.
- `utils/storage.js`: تخزين الأعمال والمفضلة في المتصفح.
- `utils/media.js`: تحويل روابط المشاهدة إلى روابط YouTube/Vimeo موثوقة والتحقق من الوسائط.
- `utils/auth.js`: عميل واجهة المصادقة (لا يحتفظ بأي كلمة مرور أو رمز جلسة).
- `server/auth.js`: التحقق من كلمة المرور، توقيع الجلسات، وتحديد المعدّل على الخادم.
- `api/admin/`: دوال Vercel لواجهات الدخول والجلسة والخروج.
- `pages/`: الرئيسية والمشاهدة وتسجيل الدخول والإدارة.
- `public/images/`: صور وملصقات محلية تُخدم من المسار `/images/`.
